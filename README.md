# Thórus Engenharia — Sistema de Gestão de Projetos

Este repositório reúne os materiais de trabalho compartilháveis do projeto. A aplicação será construída em fases.

## Objetivo

Dar à equipe Thórus uma visão única por projeto para acompanhar responsáveis, fases, tarefas, definições técnicas, alterações, eventos legais e referências documentais, mantendo histórico consultável.

## Fase atual: Fase 1 — MVP manual

A primeira entrega prevê interface interna, banco de dados, acesso por papéis e operação manual completa. A equipe poderá cadastrar e atualizar projetos, tarefas, definições, eventos e links de documentos sem depender de integração externa. Asana e Drive serão conectados na Fase 2; na Fase 1, somente a estrutura técnica e os mapeamentos ficam preparados.

As seis pastas principais seguem o padrão compartilhado pela Thórus: entregas/aprovações, trabalho, obsoletos, arquivos externos, modelos e checklist. Transcrição bruta e registros internos de metodologia não são incluídos neste pacote.
